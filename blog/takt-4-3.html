Takt 4.3: fewer silent failures, a faster way to apply rules

October 2026 · 3 min read

Takt v4.3.0 went live in the Chrome Web Store on 7 October. There is no headline feature this time. This release is mostly about things that failed without telling you, which is the worst kind of bug.

Our user base has also grown, to 16 users now 🎉.

Duplicate prevention now works everywhere

Two bugs were hiding here. Duplicate prevention stopped firing after Chrome put the extension to sleep and woke it again, and it only ran in Rules mode. Both are fixed: it now runs in every grouping mode (Rules, Category, AI or None) and survives the extension being idle.

New

  • Apply now. The rule editor has an "Apply now" checkbox, on by default. Save a rule and your open tabs are regrouped straight away, across all windows. Untick it to just save the rule.
  • Quick Switch shows every open tab. The 50-tab limit is gone. Tabs are listed most recently used first, so pressing Enter takes you back to the tab you were on before.
  • Groups follow the window you are in (Premium). With cross-window auto-collapse on, switching between Chrome windows expands the group of your active tab and collapses the groups in the windows you left.
  • New tabs land in domain order. When a rule moves a tab into an existing group, it goes next to the other tabs from the same site instead of at the end.

No more silent failures

  • AI grouping on the free tier did nothing and still reported success when you already had five groups. It now tells you the limit is reached.
  • "Suggest rules" hid itself when the on-device model was downloading, unavailable or returned nothing. It now shows what is happening, with a Retry button on errors.
  • Importing a full backup imported zero rules. It now imports them, reports how many duplicates it skipped, and shows a clear error for an invalid or oversized file.
  • "Grant all permissions" left out Downloads access. Grant all and Revoke all now cover every optional permission.

Focus fixes

  • A tab you just opened stays active when it joins the Others group (Premium), and the group expands if it was collapsed.
  • A rule with auto-collapse no longer throws you off the tab you are on. The group starts expanded if your active tab is in it.

One thing you should know: uninstall feedback

If you uninstall Takt, Chrome now opens a short feedback page on taktabs.com. The link carries six coarse, anonymous values: version, plan, a rough install age, grouping mode, a rough rule count and language. No URLs, no tab titles, no identifiers. The form is optional, and the privacy policy has a new section describing exactly what is sent and how long it is kept.

Takt itself still has no account and no telemetry.
