Takt 4.1 and 4.2: duplicate prevention is now free

September 2026 · 3 min read

Takt v4.1.0 and v4.2.0 went live in the Chrome Web Store last week. The version jump is because, by the end, there was more in it than what 3.0.0 was going to be.

Our user base has also grown, to 10 users now 🎉.

Duplicate prevention is now free

This release changes what the free tier includes: duplicate prevention is now free, unrestricted and enabled by default. It was previously a paid feature. It is the thing that helps most users on day one, and putting it behind the paywall didn't make any sense.

New features

This release also adds new features and ships the work announced in previous updates:

  • A rule tester. Paste a URL and it tells you which of your rules actually fires for it. There are also match previews before you save a rule, and up/down reordering that sets match priority. Debugging rules by opening tabs and guessing was miserable.
  • A tabs pane in the popup listing every open tab by group, with live search on title or URL and click to focus.
  • Sort by domain inside a group, and an Expand All command to complete the Group/Ungroup/Collapse/Expand set.
  • Group by Category, covering 20+ categories and hundreds of recognized domains, with no rules to write.
  • Smart Group with AI, using Chrome's built-in on-device model. Nothing leaves the browser.
  • Six languages across the extension, the website and the documentation.

Improvements

  • Onboarding has been reworked. It groups your tabs immediately after you create your first rule.

Bug fixes

  • AI grouping behaving strangely. It no longer stalls with a stuck button, it assigns every tab to a matching group, and it keeps same-domain tabs together. It now also includes hostnames in what the model sees, which made the results much better. The first run starts Chrome's model download and shows progress instead of silently falling back to heuristic grouping (expect a few small bugs here, as this hasn't been extensively tested yet).
  • Restarting Chrome no longer creates a second set of groups on top of the ones Chrome restored.
  • Tabs no longer switch on their own while you browse or while a session is being restored.
  • URL protocol validation on tab creation.

Takt stays local-first: no account, no telemetry, nothing leaving your browser.
