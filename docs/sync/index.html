File Sync

Keep your rules, profiles, sessions and hibernated tabs on all your computers, by writing to a folder your cloud client already watches. When the folder and this browser hold different data, Takt asks you what to keep.

Premium feature. File Sync requires a Premium subscription.

$3/month $30/year save 17%

How it works #

Takt writes five JSON files to a folder you choose. Your cloud desktop client — Google Drive, iCloud Drive, Dropbox, or any other — detects the new or changed files and uploads them. On your other computers, the client downloads the files. There, Sync Now reads the folder before it writes. A browser with no data of its own takes the data from the folder. A browser with its own data asks you what to keep.

Takt handles the reading and writing. Your cloud client handles the transfer. No account linking or OAuth is required on Takt's side.

Setting up sync #

  1. Open the Takt Options page and go to the Settings tab.
  2. Scroll to the File Sync section.
  3. Click Choose Folder…. Chrome will open a folder picker.
  4. Navigate to a folder inside your cloud client's local directory — for example:
    • Google Drive/My Drive/Takt/
    • iCloud Drive/Takt/
    • Dropbox/Takt/
    You can create a new subfolder called Takt inside your cloud folder directly from the picker.
  5. Click Select. Takt stores a reference to that folder.
  6. Click Sync Now. Takt reads the folder, then writes your data or asks you what to keep.

Takt stores a handle to the folder, not the folder path as a string. Chrome remembers this handle across sessions, so you don't need to pick the folder again every time you open the browser — unless the folder is moved or deleted.

What gets synced #

Takt writes five files to the chosen folder:

File Contents
rules.json All your grouping rules
profiles.json All your profiles and their rule assignments
sessions.json All your saved sessions
hibernated.json All your hibernated tabs
meta.json Sync timestamp and extension version

Takt compares the files as one set. Conflicts are not left to your cloud client: if the folder changed since this browser last synced, Takt writes nothing and asks you what to keep.

Sync Now #

Click Sync Now to sync with the folder right away. Takt first reads the five files in the folder. If the folder holds no Takt data, or only this browser changed, Takt writes its data there. If nothing changed, nothing is written. If this browser has no data of its own, Takt takes the data from the folder. If the folder changed and this browser has data of its own, Takt writes nothing and asks you what to keep. The Last synced timestamp updates when the sync succeeds.

Use Sync Now after making a batch of changes you want to push to your other devices right away.

Auto-sync #

Enable Auto-sync on every change to have Takt sync with the folder automatically whenever your rules, profiles, sessions or hibernated tabs change. Takt waits about 2 seconds after the last change, so rapid edits are batched into one sync. Like Sync Now, auto-sync reads the folder before it writes.

Auto-sync runs in the background. If the write fails (for example, if the folder permission was lost after a browser restart), Takt surfaces a Re-authorize prompt the next time you open the Options page. If the folder changed since this browser last synced, Takt shows a ! badge on its icon and one notification, and writes nothing until you choose.

When another computer has different data #

Sync Now and auto-sync read the folder before they write. Takt compares the content of the folder with this browser's data and with what the folder held at this browser's last sync. If the folder changed since then and this browser has data of its own, Takt writes nothing and asks you what to keep. Nothing is overwritten until you choose.

File Sync never replaces this browser's data by itself. Changes made on another computer reach this browser when you choose Keep what is in the folder or Merge both.

After Sync Now, the choice opens right away. If auto-sync finds the difference, Takt shows a ! badge on its icon and one notification. Click the notification to open the Options page, where you make the choice. Until then, auto-sync writes nothing.

You have three choices:

  • Keep what is in the folder — replaces the data on this browser with the data in the folder.
  • Keep what is on this browser — replaces the data in the folder with the data on this browser.
  • Merge both — keeps the data from both sides, then writes the result to this browser and to the folder.

The two Keep choices replace data, so Takt asks you to confirm first. They cannot be undone. Cancel writes nothing, and the choice stays open.

What Merge both does:

  • Rules and profiles — everything on this browser stays as it is, and the entries from the folder are added. An identical entry is kept once. A rule or profile whose name is already used gets a number, for example Work (2). Added profiles are inactive, have no schedule, and point to the merged rules.
  • Sessions — the sessions from both sides, at most 50; the most recent are kept.
  • Hibernated tabs — one entry per address, at most 200; this browser's entries come first.
  • Settings — not involved: the folder holds no settings.

Takt does not ask you in these cases:

  • The data is the same on both sides. Nothing is written.
  • This browser has no data of its own: no profiles, sessions or hibernated tabs, and no rules or only the example rules Takt adds at install. Takt takes the data from the folder.
  • The folder holds no Takt data yet. Takt writes this browser's data there.
  • Only this browser changed since the last sync. Takt writes its data to the folder.

Chrome Sync and Takt #

Chrome Sync works on every plan, including the free plan. It is a Chrome feature: when it is on, Chrome copies Takt's rules, profiles and synced settings between the browsers signed in to your Google account. Sessions and hibernated tabs never travel by Chrome Sync.

Chrome applies the data from your Google account first, and Takt cannot stop it. That is why Takt keeps its own copy of this browser's rules, profiles and synced settings. If Chrome Sync brings rules or profiles that share no entry with the ones this browser had, Takt keeps working with what Chrome brought and asks you what to keep. Your copy stays until you choose.

You have three choices:

  • Keep what came from your Google account — keeps what Chrome brought and deletes Takt's copy of what was on this browser.
  • Keep what was on this browser — puts back the rules, profiles and settings this browser had. Your other browsers that use Chrome Sync get them too.
  • Merge both — merges the rules and profiles from both sides, the same way as for Drive Sync and File Sync. Settings stay as they came from your Google account. Sessions and hibernated tabs are not involved.

The two Keep choices ask you to confirm first. They cannot be undone. Cancel changes nothing, and the choice stays open.

If the result is too large for Chrome Sync (8,192 bytes per item), Takt refuses it and nothing changes. While the choice is open, File Sync auto-sync and the 15-minute Drive Sync wait.

Takt does not ask you when:

  • Takt itself made the change.
  • Another browser made an ordinary update, and its rules or profiles share entries with this browser's.
  • This browser had no data of its own, or only the example rules Takt adds at install.
  • Only settings changed.

On the free plan, Takt uses at most 5 rules, also after any sync. Extra rules that arrive by sync are kept, marked Locked in the rules list, and not used. If you choose Merge both on the free plan, at most 5 rules are kept, this browser's first, and Takt tells you how many were left out.

In AI and Category modes, the free plan makes at most 5 groups, the biggest first. The Others group needs Premium.

Settings that belong to one computer are no longer synced: the File Sync folder and its auto-sync; whether Drive Sync and its auto-sync are on, the account email and the last sync time; granted permissions; and whether onboarding is done.

Import from Folder #

Click Import from Folder to pull data into Takt from any folder on your disk — such as a cloud-synced folder on another device:

  1. A system folder picker opens. Navigate to the folder that contains the Takt sync files (rules.json, profiles.json, sessions.json).
  2. Takt verifies that at least one expected file is present. If none are found, the import is cancelled with an error message.
  3. Each file is read, size-checked (5 MB limit), parsed, and validated for structure and security before any data is written.
  4. Valid data is added to your current Takt data, and imported entries get new IDs. A rule, profile or session whose name is already used here, and a hibernated tab whose address is already in the list, is skipped. Imported profiles are inactive. Their rule links point to the imported rules, or to the rule here with the same name; a link to a rule that is not in the import is dropped. Takt then shows how many rules and profiles were added and skipped, and how many sessions and hibernated tabs were added.

If a file is missing (for example, sessions.json doesn't exist yet), that data type is skipped without error.

Don't import from your active sync folder. Sync Now already reads that folder and asks you what to keep. Import from Folder only adds entries whose name is not used here, so importing from your sync folder can bring back rules, profiles or sessions you deleted or renamed since the last sync. Use Import from Folder to bring in data from a different device or a backup, not from the folder you sync to.

Re-authorizing after permission loss #

In most cases Chrome remembers your folder permission across browser restarts and sync continues to work without any action. Occasionally permission can be lost — for example if the folder was moved or deleted, the extension was reinstalled, or Chrome's permission store was cleared.

When Takt detects that folder access was lost, it shows a yellow warning in the File Sync section:

Folder access was lost. Click Re-authorize to restore sync.

Click Re-authorize and Chrome will ask for permission to access the same folder again — no folder picker, just a one-click confirmation. Once granted, sync resumes automatically.

Clearing the sync folder #

Click Clear next to the folder name to disconnect Takt from the sync folder. This removes Takt's reference to the folder and turns off auto-sync. It does not delete the files from your disk or from your cloud storage.

You can pick a different folder at any time by clicking Choose Folder… again.

Limits & behaviour #
